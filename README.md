# eps-con.com — Lovable Export Deploy Projesi

**Status:** Kurulum aşamasında  
**Başlangıç:** 2026-07-07

---

## Proje Amacı

Lovable.dev'den export edilen eps-con.com sitesinin üretim ortamına deploy edilmesi.

## Yapı

```
eps-con/
├── .claude/                    ← Claude Code konfigürasyonu
│   └── CLAUDE.md              ← Proje kuralları
├── .gorevler/                 ← Ortak çalışma sistemi
│   ├── KIM.md                 ← Kişi adı
│   ├── backups/               ← Dosya versiyonları
│   └── aksiyon-paketleri/     ← Planlı görevler
└── [Lovable Export Dosyaları]
```

## Sıradaki Adımlar

1. **Lovable export** dosyalarının indirilmesi
2. Proje yapısının analizi
3. CLAUDE.md ve memory sisteminin update edilmesi
4. Deploy stratejisinin belirlenmesi
